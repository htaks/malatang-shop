# Malatang Shop 🍲

麻辣湯（マーラータン）屋さんを経営するブラウザゲームです。
コンベアベルトで流れてくる食材を鍋に入れて、お客さんに料理を提供しよう！

## 技術スタック

- **Next.js** — アプリケーションフレームワーク
- **TypeScript** — 型安全な開発
- **Tailwind CSS** — スタイリング
- **Playwright** — E2Eテスト

## セットアップ

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev
```

ブラウザで `http://localhost:3000` を開いてプレイできます。

## テスト

```bash
# Playwright によるE2Eテスト
npx playwright test
```

## 開発チーム

本プロジェクトは **チームA** によって開発・運用されています。

| 役割 | 担当 | 説明 |
| --- | --- | --- |
| 司令塔（PM） | メイト | タスクの統括・指示出し・進行管理 |
| 実装担当 | ドキュ | 機能実装・コーディング・成果物の作成 |

- **開発体制**: 司令塔「メイト」が全体の方針を決定し、サブエージェント「ドキュ」が実装を担当する分業体制で進めています。
- **コミュニケーション**: タスクごとに指示 → 実装 → レビューのサイクルを回し、確実な品質を担保しています。
- **コントリビューション**: バグ報告や機能提案は Issue / Pull Request にてお気軽にどうぞ！
